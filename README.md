# 排版防线 / Editorial Defender

一款受网页排版引擎启发的生存射击游戏。背景不是普通贴图，而是一整层会“避让”玩家的文字墙；玩家需要驾驶坦克在动态排版网格里生存、射击并收集增益道具。

它不是传统意义上的“坦克打怪”原型，而是把网页排版、浮动避让和文本重组这些前端语义，重新翻译成了可游玩的空间机制。

## 玩法概览

你需要在屏幕中央附近建立生存节奏：

- 操控坦克在文字墙之间游走
- 利用文字的动态避让制造临时通道
- 射击敌对节点并击碎局部文本障碍
- 抢在敌人包围前收集增益道具，拉开生存窗口

随着时间推进，敌人刷新会越来越密集，场面会从可控的排版扰动，逐渐演变成高压的文字风暴。

## 特性

- 使用 `@chenglou/pretext` 进行文本预处理和逐行布局
- 通过中间安全区 + 双侧槽位模拟“文字绕开主体内容”的排版效果
- 逻辑更新与渲染分离，便于继续做性能优化
- 集成 `stats.js` 实时观察渲染 FPS / 帧耗时
- 纯 TypeScript + DOM 分层渲染，便于直接调整玩法和视觉细节

## 操作方式

- 鼠标移动: 控制坦克朝目标位置平滑移动
- 鼠标左键按住: 持续开火
- 触摸开始 / 拖动: 在移动端控制坦克并持续攻击
- 目标: 尽可能长时间生存并提高分数

## 设计亮点

### 把“排版”做成地形

文字层不是静态背景，而是具备物理感的动态障碍。玩家靠近时，文字会被推开；离开后，文字又会缓慢回弹，形成一种介于 UI 与地形之间的独特空间反馈。

### 把“绕排”做成世界规则

项目没有直接手写整张文字地图，而是利用 `pretext` 逐行布局，让文本天然绕开中间安全区。这让场景结构既稳定又保留了真实排版感。

### 把“文本碎裂”做成战斗反馈

玩家子弹不仅能打敌人，也能击碎文字墙。战斗过程会不断重塑掩体，强化“排版结构正在崩坏又重组”的主题体验。

## 核心机制

### 文本布局

背景文字不是手写坐标铺排，而是通过 `pretext` 自动完成：

- `prepareWithSegments()` 预处理语料
- `layoutNextLine()` 按给定宽度逐行布局
- `carveSlots()` 根据中间安全区，把每一行切成左槽、右槽或整行槽

这让文字层既保留了真实排版感，也方便做类似“浮动避让”的特殊场景。

### 游戏循环

- `update()` 以固定 60 FPS 执行，负责移动、碰撞、刷怪、buff 与生命周期
- `renderLoop()` 使用 `requestAnimationFrame()`，负责把状态同步到 DOM
- `stats.js` 挂在 `renderLoop()` 外围，显示实时 FPS 和渲染耗时
- 全部持续时间逻辑都依赖 `frameCount`

### 当前实体

- `Tank`: 玩家坦克
- `TextBlock`: 可被击碎并会重生的文字墙单元
- `Bullet`: 敌我子弹
- `Enemy`: 从边缘刷新的敌对节点
- `PowerUp`: 冻结、连发、无敌、环射四类增益
- `Particle`: 爆炸和命中特效

### 增益道具

- `freeze`: 暂停敌人的移动与射击节奏
- `rapid`: 显著缩短玩家开火间隔
- `invincible`: 玩家免疫伤害，并可直接撞毁敌人
- `barrage`: 玩家每次开火都会向 360 度同时发射一圈子弹

## 最近的性能优化

本次已完成的优化包括：

- `pretext` 语料 prepared 结果缓存，减少重复 `prepareWithSegments()`
- 字形宽度缓存，减少 `canvas.measureText()` 调用
- 文字空间分桶，降低“子弹撞文字”的扫描成本
- `TextBlock` 脏更新渲染，减少无效 DOM 样式写入
- buff 文案仅在内容变化时才更新
- 多处圆形碰撞改为平方距离比较，减少开方开销

这些优化的目标不是单纯“跑得更快”，而是保证当文字、粒子、子弹和敌人同时变多时，游戏仍然维持稳定、清晰的操作反馈。

## 调试工具

- 右下角已接入 `stats.js` 调试面板
- 默认显示 `FPS`，点击面板可切换到 `MS`，在支持的环境下也可查看内存面板
- 该面板基于 `requestAnimationFrame()` 采样，反映的是实际渲染帧率而不是逻辑更新频率

## 后续可以继续优化的方向

- 为敌人与玩家子弹碰撞也加入空间分桶
- 为子弹、敌人、粒子层加入更细的脏更新
- 把更新循环统一为 `requestAnimationFrame + fixed timestep`
- 在移动端进一步降低粒子和阴影特效开销

## 适合继续扩展的方向

- 新增不同形状的安全区，做出更强的“多栏排版”视觉
- 增加 Boss 或特殊敌人，让它们具备改写文本地形的能力
- 引入主题语料包，让不同关卡拥有不同语言与排版气质
- 把当前生存模式扩展成关卡制或限时挑战模式
